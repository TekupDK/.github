## 🚀 About Tekup Portfolio

Tekup Portfolio is a comprehensive ecosystem of business management tools designed to streamline operations, enhance productivity, and leverage cutting-edge AI technology. We build modern, type-safe, and scalable solutions for businesses with a focus on:

- 🗄️ **Intelligent Knowledge Management** (TekupVault)
- 🧹 **Professional Cleaning Operations** (Rendetalje)
- ☁️ **Unified Cloud Dashboard**
- 🤖 **AI-Powered Automation** (MCP Servers)

## 🛠️ Technology Stack

- **TypeScript** - Strict mode for type safety
- **Node.js 18+** - Modern JavaScript runtime
- **React & Next.js** - Web applications
- **React Native** - Cross-platform mobile
- **PostgreSQL & Supabase** - Database and backend
- **Turborepo & pnpm** - Monorepo management
- **Docker** - Containerization
